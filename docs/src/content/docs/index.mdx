---
title: steamworks.js
description: Node.js and Electron bindings for the Steamworks SDK, for Steam Workshop, achievements, stats, cloud, overlay and networking.
---

Use the Steamworks SDK from Node.js or Electron. The package wraps the native SDK and ships typed declarations.

This is a personal fork of [ceifa/steamworks.js](https://github.com/ceifa/steamworks.js), built on a fork of [steamworks-rs](https://github.com/Noxime/steamworks-rs). It is shaped for working with coding agents and for the Steamworks features my own projects need. For the general-purpose library, use upstream.

Install it with npm:

```sh
npm i @hagicode/steamworks.js
```

- [Getting started](/guide/getting-started/) covers the API, installation and the Electron setup.
- [Steam Workshop](/guide/workshop/) covers screenshots, previews, content updates, item dependencies and multilingual items.
- [Agent skills](/skills/steamworks-js/) are task guides for Workshop publishing, updates, queries, client state and stats.
