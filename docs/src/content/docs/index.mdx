Use the Steamworks SDK from Node.js or Electron. The package wraps the native SDK and ships typed declarations.

This is a personal fork of [ceifa/steamworks.js](https://github.com/ceifa/steamworks.js), built on a fork of [steamworks-rs](https://github.com/Noxime/steamworks-rs). It is shaped for working with coding agents and for the Steamworks features my own projects need. For the general-purpose library, use upstream.

Install it with npm:

```sh
npm i @hagicode/steamworks.js
```

## What you can do with it

- **Steam Workshop (UGC).** Create items of any file type, publish and update them, and manage their previews, screenshots, videos, metadata, key-value tags, content descriptors, game-version ranges and per-language text. Link items to the items and apps they require. Act as the logged-in user: subscribe, download, vote, favorite and track playtime.
- **Friends and identity.** Read the friend list, states and avatars, send game invites, and get session tickets.
- **Stats, achievements and leaderboards.** Float stats, global unlock percentages, and leaderboard uploads and downloads.
- **Networking.** The original P2P packet API, plus Networking Sockets, Messages and Utils.
- **Servers and play together.** Server browser queries, lobbies, Remote Play sessions and invites, the Steam timeline and screenshots.
- **Agent skills.** Task guides that let a coding agent publish, update, query and report on Workshop items with confirmation before every write.

Anything marked **unverified** in the guides has not been run against a live Steam client yet.
